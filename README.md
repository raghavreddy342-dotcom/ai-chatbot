# Student AI Chatbot (Python)

## Description
This project is a simple rule-based AI chatbot built using Python. It responds to user inputs using keyword-based logic.

## Features
- Handles basic user queries
- Provides responses for coding, study tips, and general questions
- Interactive command-line interface

## Tech Used
- Python

## How to Run
1. Download the file
2. Run: python ai_chatbot.py
